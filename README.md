# Asistente-Legal-RAG-Cuernavaca
Asistente (chatbot) para consultas y cuestiones relacionadas al reglamento de tránsito en el municipio de Cuernavaca, Morelos. Orquestado mediante Dify como Framework y utilizando (RAG) reglamentos de tránsito para carreteras y puentes, vialidad, movilidad y transporte y seguridad vial del estado de Morelos
